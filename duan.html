Giới Thiệu Tác Giả

Xin chào! Tôi là Nhiếp Ảnh Gia Cảnh Quan

Tôi đam mê du lịch và ghi lại vẻ đẹp chân thực của tự nhiên. Trang web này là dự án hoàn thành khóa học Thiết kế Web cơ bản, thể hiện các kỹ năng về HTML5 Semantic, CSS Grid, Flexbox, Box Model và Trải nghiệm Truy cập (Accessibility).

Bảng Kiểm Yêu Cầu Dự Án (Checklist):

  • ✅ Cấu trúc trang web 3 trang mượt mà.
  • ✅ Nút Skip to Main Content ẩn/hiện chuẩn khi nhấn TAB.
  • ✅ Thanh điều hướng Flexbox đẹp mắt với hiệu ứng :hover.
  • ✅ Tất cả hình ảnh tuân thủ Box Model (padding, border, border-radius, margin).
  • ✅ Trang Thư viện sử dụng CSS Grid (ít nhất 2-3 cột).
  • ✅ Áp dụng bộ chọn :nth-child tạo viền và góc bo khác biệt cho ảnh chẵn/lẻ.
  • ✅ Đạt tiêu chuẩn HTML/CSS và WAVE Accessibility (thẻ alt đầy đủ).
